Ta-form and nakatta-form

JLPT N5・Verb Conjugation

Meaning

Past tense, plain style. The た form is built exactly like the て form, replacing て with た (and で with だ): for godan verbs use the sound changes (e.g., 話す→話した, 急ぐ→急いだ); for ichidan verbs drop る + た (e.g., 見る→見た). The negative past (nakatta form) changes ない→なかった.

Pattern

ta-form = て→た (で→だ) ／ nakatta-form = ない→なかった

Examples

  • 走る→走った、見る→見た hashiru → hashitta (ran), miru → mita (saw)
  • 飲まない→飲まなかった nomanai → nomanakatta: didn't drink
