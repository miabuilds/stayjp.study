Plain form summary

JLPT N5・Verb Conjugation

Meaning

The four plain forms: dictionary form / nai form / ta form / nakatta form. For i-adjectives: い / くない / かった / くなかった (e.g., 美しい / 美しくない / 美しかった / 美しくなかった). For na-adjectives and nouns: だ / じゃない / だった / じゃなかった.

Pattern

verb・i-adjective・na-adjective・noun: 4 conjugations each

Examples

  • 買う/買わない/買った/買わなかった kau / kawanai / katta / kawanakatta: the four verb forms
  • 大切だ/じゃない/だった/じゃなかった taisetsu da / ja nai / datta / ja nakatta: the four na-adjective forms ("important")
