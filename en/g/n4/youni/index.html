～ように (purpose)

JLPT N4・Conjunctions & Cause

Meaning

Means "so that ~ / in order to be able to ~." Used with non-volitional verbs, potential forms, or negative forms (something you hope will happen rather than a direct action you control).

Pattern

dictionary form／nai-form ＋ように

Examples

  • 寝坊しないように目覚ましを二つ設定します。 I set two alarms so that I won't oversleep.
  • 試験に受かるように、毎晩復習しています。 I review every night so that I can pass the exam.
