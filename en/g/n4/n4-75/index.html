Verb conjugation order

JLPT N4・Verb Conjugation

Meaning

All verb conjugations start from the dictionary form and branch out (ます-form → て-form → potential → passive → causative, etc.). The key is first identifying the verb's class (godan / ichidan / irregular), since each class conjugates differently.

Pattern

masu-form→て form→potential form→passive form→causative form, etc.

Examples

  • 飲む：飲みます/飲んで/飲める/飲まれる/飲ませる "飲む" (to drink): 飲みます / 飲んで / 飲める / 飲まれる / 飲ませる — an overview of the conjugations.
  • 見る：見ます/見て/見られる/見させる "見る" (to see): 見ます / 見て / 見られる / 見させる — an overview of the conjugations.
