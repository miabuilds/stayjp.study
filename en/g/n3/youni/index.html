～ように

JLPT N3・Others

Meaning

"So that ~ / in order to be able to ~." A way of expressing purpose that pairs with non-volitional verbs, potential forms, or negatives (unlike 「ために」, which takes volitional verbs).

Pattern

dictionary form／nai-form ＋ ように

Examples

  • 忘れ物をしないように、前日に荷物を準備する。 So that I don't forget anything, I pack my things the day before.
  • 後ろの人にも聞こえるように、マイクを使った。 So that the people in back could hear too, I used a microphone.
  • 最終便に間に合うように、早めに空港へ向かった。 So that I'd make the last flight, I headed to the airport early.
